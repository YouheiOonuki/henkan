PDF 結合・分割・回転の使い方

  1. 「結合」「分割」「回転・ページ整理」から選ぶ
  2. PDF を選ぶ（ドロップも可。複数を一度に）
  3. 順番・ページ・向きを決める
  4. 保存のボタンを押す

結合はファイルの順に、ページ整理はページの順に並べ替えます。ページの縮小画像は出さず、向きと縦横の形だけを出します。

PDF をアップロードしないしくみ

PDF の読み込み・結合・分割・回転は、この端末のブラウザの中（Web Worker）で行います。ファイルの中身をサーバーに送る処理はありません。

使っているもの
  • PDF の読み書き: pdf-lib 1.17.1（MIT License）。このサイトに置いた写しを、最初にファイルを選んだときに読み込みます
  • 回転: ページの Rotate（時計回り、90 の倍数）を書き換えます。中身の画像や文字は作り直しません
  • 新しい PDF に写すので、元の文書情報（タイトル・作成者など）・しおり・フォームの設定は持ち込みません。文書情報は「くわしい設定」で残せます

根拠: ISO 32000-1:2008（PDF 1.7）7.7.3.3 Table 30（Rotate）、7.5.5 Table 15（Encrypt）、7.7.2 Table 28（Outlines・AcroForm）。最終確認日 2026-10-01。

PDF の分割のページの書き方

「1-3, 5」と書くと、1〜3 ページと 5 ページの 2 つのファイルに分けます。「5-」は 5 ページから最後まで、「3-1」は逆の順です。

分け方の種類
  • 範囲ごとに別のファイル: カンマで区切った範囲ごとに 1 つ
  • 指定したページを 1 つのファイルに: 書いたページを書いた順につなげる
  • 1 ページずつ・決まったページ数ずつ: 最後のファイルは残りのページ

全角の数字・「〜」「、」も読めます。複数のファイルを入れたときは、つなげた順のページ番号で数えます。2 つ以上のファイルは ZIP にまとめて保存できます。

よくある質問

パスワード付きの PDF を結合できますか？
できません。開くときのパスワードも、編集の制限だけのものも、暗号化された PDF は読めないと表示します。PDF を作ったソフトなどで保護を外して保存し直してから入れてください。
PDF の結合でしおり（目次）は残りますか？
残りません。ページを新しい PDF に写すしくみなので、しおりと入力フォームの設定は持ち込みません。フォームの入力欄は、見た目は残っても入力できなくなることがあります。
スマホでも PDF を結合できますか？
できます。ファイルを選ぶボタンから入れ、ファイルの順番は ↑↓ のボタンで並べ替えます。大きなファイルは端末のメモリが足りずに止まることがあるので、合計 100MB を目安にしてください。

ご利用上の注意・データの扱い

  • 選んだ PDF はこの端末のブラウザの中だけで処理し、外部には送信しません。保存もしないので、ページを閉じると消えます。
  • ページには広告とアクセス解析（Cloudflare Web Analytics）のスクリプトがありますが、PDF の中身は渡しません。
  • 結果は元の PDF と見比べてから使ってください。データの出どころとライセンスもあわせてどうぞ。
