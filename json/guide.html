▶ JSON 整形 を使う

JSON 整形の使い方

  1. JSON を貼る（ファイルを開く・ドロップも可）
  2. 正しければ整えた形が、誤りがあれば行・列と理由が出る
  3. 出力の形（整形・1 行に詰める・CSV にする）を選ぶ
  4. コピーするか、ファイルに保存する

JSON のエラーの行と列

行は改行で数え、列はその行の何文字目か（全角も絵文字も 1 字）です。「入力欄のその位置へ」で誤りの字を選べます。

よくある誤りと、出る理由
  • 最後の要素の後ろのカンマ [1, 2,]: 「「]」の前に余分な「,」があります」
  • シングルクォート {'a': 1}・引用符の無い名前 {a: 1}・コメント // …
  • 0 で始まる数 0123・NaN・True（大文字）
  • 文字列の中の改行・タブ（\n・\t と書く）
  • 全角の「：」「，」・全角スペース

文法は RFC 8259（2017 年）に合わせています。先頭の BOM は読み飛ばして、その旨を出します。

数と文字列は書いたとおりに残す

整形しても、数と文字列は 1 文字も変えません。空白と改行（と、選べば名前の順）だけを変えます。

くわしく

JavaScript の JSON.parse を通すと、12345678901234567890 は 12345678901234567000 に、1.10 は 1.1 に、"\u3042" は "あ" になります。RFC 8259 の 6 章は、数の精度は読む側の実装しだいで、整数が一致すると言えるのは ±(253−1) の範囲だとしています。このツールは自前の読み取りで、書いてあった文字をそのまま出します。この範囲を超える整数があるときは、結果の下に書きます。

CSV にするとき: 一番外が配列で、要素がオブジェクトなら名前を列にします（出てきた順）。入れ子のオブジェクトは「親.子」の列に、配列は JSON のまま 1 つのセルに入れます。

よくある質問

JSON のエラーの場所がわかりません
誤りのある行と、その行の何文字目かを日本語の理由と一緒に出します。前の 2 行と位置の印（^）も出るので、最後のカンマや引用符の閉じ忘れを見つけやすくなります。
JSON の大きな数字が変わる（丸められる）のはなぜですか？
JavaScript の数は倍精度のため、およそ 9007 兆を超える整数は丸められます。このツールは数を書いてあったとおりに出すので、ID などの長い整数も変わりません。
JSON を CSV にして Excel で開けますか？
はい。出力の形で「CSV にする」を選び、「BOM を付ける」をオンにして保存すると、Excel で文字化けせずに開けます。

ご利用上の注意・データの扱い

  • 貼り付けた文章やファイルは、この端末のブラウザの中だけで処理し、外部には送信しません。文章は保存しません。
  • 設定はこの端末のブラウザ（localStorage、キー henkan_settings）にだけ保存され、外部には送信されません。書き出し・読み込み・消去はツールの画面のボタンから。
  • 結果は元の文章と見比べてから使ってください。データの出どころとライセンスもあわせてどうぞ。
