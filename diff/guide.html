▶ テキスト差分 を使う

テキスト差分の使い方

  1. A に元の文章、B に新しい文章を貼る（ファイルを開く・ドロップも可）
  2. 違いが色分けで出る（赤は A だけ、緑は B だけの行・字）
  3. 「比べ方」で単位（行・文字）と、同じとみなす違いを選ぶ
  4. 「unified 形式でコピー」で diff -u と同じ形の文字にする

違いの見つけ方

違いがいちばん少なくなる分け方を、Myers の差分アルゴリズム（1986 年）で探します。GNU diff と同じ系統の方法です。

くわしく
  • 行単位では、変わった行どうしを同じ位置で組にして、似ている組だけ行の中の違う字を濃い色で示します
  • 文字単位では、濁点つきの半角カナ（ｶﾞ）や絵文字の結合も 1 字として比べます。1 つ 20 万字まで
  • 「同じとみなす違い」を選んでも、表示は元の文字のままです。比べるときだけ、空白を除く・小文字にする・全角半角をそろえる（全角・半角の対応表と同じ規則）
  • 改行コード（CRLF・LF）と最後の行の改行の有無は比べず、違うときは結果の下に書きます
  • 違いがとても多い大きな入力では、途中から速さを優先します（最短でない分け方になることがあり、そのときは結果の下に書きます）
  • 計算は画面とは別の処理（Web Worker）で行います。6 万行・約 230 万字の 2 つの文章（600 か所の違い）で、結果まで約 1.5 秒でした（2026-09-25、PC の Chromium で計測）

よくある質問

全角と半角の違いを無視して比較できますか？
はい。「比べ方」の「全角・半角」を選ぶと、ｶﾞ と ガ、Ａ と A、全角と半角のスペースを同じとみなします。表示は元の文字のままです。
Word や PDF の文章の差分を比べられますか？
文字だけを比べます。Word や PDF から文章をコピーして貼れば比べられますが、書式やレイアウトの違いは比べません。
比較した文章はどこかに送信されますか？
送信しません。比べる計算はすべてこの端末のブラウザの中で行い、貼り付けた文章は保存もしません。

ご利用上の注意・データの扱い

  • 貼り付けた文章やファイルは、この端末のブラウザの中だけで処理し、外部には送信しません。文章は保存しません。
  • 設定はこの端末のブラウザ（localStorage、キー henkan_settings）にだけ保存され、外部には送信されません。書き出し・読み込み・消去はツールの画面のボタンから。
  • 結果は元の文章と見比べてから使ってください。データの出どころとライセンスもあわせてどうぞ。
