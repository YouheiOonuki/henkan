CSV 整形・変換の使い方

  1. CSV を貼る（ファイルを開く・ドロップも可。Shift_JIS も読める）
  2. 区切りが自動で決まり、表の見本と行・列の数が出る
  3. 出力の形（CSV に整える・JSON にする）を選ぶ
  4. コピーするか、ファイルに保存する（Excel 用の BOM は既定でオン）

CSV の形（RFC 4180）

書き出しは RFC 4180（2005 年）の形です。区切り・「"」・改行を含むセルだけ「"」で囲み、中の「"」は「""」にします。

くわしく
  • 読むときは RFC より広く受け入れます: 改行は CRLF・LF・CR、区切りはカンマ・タブ・セミコロン・縦棒。囲まれていないセルの中の「"」は文字として読み、注意を出します
  • 区切りの自動判定: 先頭 100 行を 4 つの候補で読み、列の数がいちばんそろうものを選びます
  • 先頭と末尾に空白があるセルも「"」で囲みます（読む側に空白を削られないように）
  • 文字コード: ファイルは UTF-8 として読み、読めなければ Shift_JIS として読みます（WHATWG Encoding Standard の shift_jis）
  • JSON にするとき: 1 行目を名前にします。空の名前は「列3」、重なった名前は「名前_2」。数にするのは 0 で始まらない整数と小数だけで、郵便番号の 0 は落としません

Excel で文字化けしない CSV（BOM）

保存するときに、UTF-8 の目印（BOM、先頭の 3 バイト EF BB BF）を付けます。Microsoft の資料も、Excel で CSV の文字コードの問題が出たら BOM 付きの UTF-8 で保存し直すよう案内しています。

くわしく

Microsoft Learn の Partner Center の資料「Excel での CSV エンコードの問題を修正する」は、英語以外の環境で問題が出たら、メモ帳で「BOM 付きの UTF-8」で保存し直してから Excel で開く手順を案内しています。Power Query（Excel の「データの取得」）の資料には、UTF-8 と推定するのはファイルが BOM で始まるときだけとあります（どちらも 2026-09-25 に確認）。BOM を嫌うプログラムに渡すときは、オフにして保存してください。コピーした文字には BOM は付きません。Microsoft Excel は Microsoft の商標です。このツールは Microsoft とは関係ありません。

よくある質問

CSV を Excel で開くと文字化けします
UTF-8 の CSV を Excel で開くと化けることがあります。このツールで開き直し、「BOM を付ける」をオンのまま保存すると、Excel でそのまま開けます。
CSV を JSON に変換できますか？
はい。出力の形で「JSON にする」を選ぶと、1 行目を名前にしたオブジェクトの配列になります。数字は既定で文字のまま、郵便番号などの先頭の 0 も残ります。
セルの中の改行やカンマはどうなりますか？
「"」で囲まれていれば、1 つのセルとして読みます。書き出すときも、改行・カンマ・「"」を含むセルは「"」で囲みます。

ご利用上の注意・データの扱い

  • 貼り付けた文章やファイルは、この端末のブラウザの中だけで処理し、外部には送信しません。文章は保存しません。
  • 設定はこの端末のブラウザ（localStorage、キー henkan_settings）にだけ保存され、外部には送信されません。書き出し・読み込み・消去はツールの画面のボタンから。
  • 結果は元の文章と見比べてから使ってください。データの出どころとライセンスもあわせてどうぞ。
